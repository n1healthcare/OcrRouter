## Output Directory Structure

When you process a document, OCRRouter creates the following directory structure:

```
output/
└── document_name/
    └── vlm/
        ├── document_name.md                    # Markdown output
        ├── document_name_layout.pdf            # Visual layout (if draw_layout_bbox=True)
        ├── document_name_model.json            # Raw model output
        ├── document_name_middle.json           # Processed structure
        ├── document_name_content_list.json     # Simplified content
        └── images/                             # Extracted images
            ├── 3a7f5e2b...jpg                 # Table image (SHA256 hash)
            ├── 8c9d1a4f...jpg                 # Formula image
            └── ...
```

**Example:**

```python
from ocrrouter import DocumentPipeline, Settings

settings = Settings(backend="deepseek", openai_api_key="key")
pipeline = DocumentPipeline(settings=settings)

result = pipeline.process("research_paper.pdf", "output/")
print(result["output_dir"])  # output/research_paper/vlm
```

## File Descriptions

### Markdown File (`.md`)

**Filename**: `{document_name}.md`

**Purpose**: Human-readable converted text

**Contents**:
- Structured markdown text
- Tables (HTML format)
- Formulas (LaTeX wrapped in `$...$` or `$$...$$`)
- Image references (`![alt](images/hash.jpg)`)
- Code blocks (with language tags)
- Lists and hierarchical content

**Use Cases**:
- Publishing to docs sites
- Content management systems
- Human review and editing
- Text search and indexing

**Example Output**:
```markdown
# Introduction to Deep Learning

Deep learning is a subset of machine learning...

## Neural Network Architecture

The basic structure follows:

$$f(x) = W \cdot x + b$$

### Training Process

| Epoch | Loss | Accuracy |
|-------|------|----------|
| 1     | 0.45 | 0.82     |
| 2     | 0.23 | 0.91     |

![Network Diagram](images/3a7f5e2b...jpg)
```

**Accessing**:
```python
result = pipeline.process("document.pdf", "output/")
markdown_text = result["markdown"]

# Or read from file
with open(result["output_dir"] + "/document.md") as f:
    markdown = f.read()
```

**Control with**: `dump_md=True` (default)

---

### Layout PDF (`_layout.pdf`)

**Filename**: `{document_name}_layout.pdf`

**Purpose**: Visual debugging file showing detected layout

**Contents**:
- Original PDF pages with overlays
- Bounding boxes around detected regions
- Color-coded content types (text, title, table, image, etc.)
- Reading order numbers

**Use Cases**:
- Quality verification
- Debugging layout detection issues
- Visual comparison with original
- Understanding document structure

**Example Visual**:
```
┌─────────────────────────────┐
│ ┌─────────────────────────┐ │  ← Title (blue box)
│ │ 1. Document Title       │ │
│ └─────────────────────────┘ │
│                             │
│ ┌─────────────────────────┐ │  ← Text (green box)
│ │ 2. This is paragraph... │ │
│ └─────────────────────────┘ │
│                             │
│ ┌─────────────────────────┐ │  ← Table (red box)
│ │ 3. [Table content]      │ │
│ └─────────────────────────┘ │
└─────────────────────────────┘
```

**Control with**: `draw_layout_bbox=True` (default)

### Model Output (`_model.json`)

**Filename**: `{document_name}_model.json`

**Purpose**: Raw VLM inference results

**Structure**:
```json
[
  [  // Page 0
    {
      "type": "title",
      "bbox": [0.157, 0.228, 0.833, 0.253],
      "angle": 0,
      "content": "Document Title",
      "score": null
    },
    {
      "type": "text",
      "bbox": [0.157, 0.270, 0.833, 0.420],
      "angle": 0,
      "content": "This is the first paragraph of text...",
      "score": null
    }
  ],
  [  // Page 1
    {
      "type": "equation",
      "bbox": [0.300, 0.400, 0.700, 0.450],
      "angle": 0,
      "content": "$$f(x) = \\int_{0}^{\\infty} e^{-x^2} dx$$",
      "score": null
    }
  ]
]
```

**Block Types**:
- `title`, `text`, `abandon` — Text content
- `table` — Tables
- `image`, `image_caption`, `image_footnote` — Images
- `equation` — Mathematical formulas
- `header`, `footer` — Page headers/footers
- `page_number` — Page numbers
- `code` — Code blocks
- `list_item` — List items

**Use Cases**:
- Model inspection and debugging
- Custom post-processing logic
- Research and analysis
- Training data extraction

**Coordinate System**: Normalized [0, 1] relative to page dimensions

**Control with**: `dump_model_output=True` (default)

---

### Middle JSON (`_middle.json`)

**Filename**: `{document_name}_middle.json`

**Purpose**: Processed structural representation with enhanced metadata

**Differences from `model.json`**:
- Hierarchical block structure
- Enhanced metadata (page indices, image paths)
- Normalized and cleaned content
- Absolute pixel coordinates

**Structure**:
```json
[
  {
    "page_idx": 0,
    "width": 1654,
    "height": 2339,
    "blocks": [
      {
        "type": "text",
        "bbox": [259, 533, 1377, 593],
        "content": "Introduction to Deep Learning",
        "angle": 0,
        "text_level": 1
      },
      {
        "type": "table",
        "bbox": [260, 650, 1380, 1200],
        "table_body": "<table>...</table>",
        "img_path": "images/3a7f5e2b...jpg",
        "angle": 0
      }
    ]
  }
]
```

**Use Cases**:
- Secondary development
- Custom transformations
- Layout-aware processing
- Structured data extraction

**Coordinate System**: Absolute pixels

**Control with**: `dump_middle_json=True` (default)

---

### Content List (`_content_list.json`)

**Filename**: `{document_name}_content_list.json`

**Purpose**: Simplified flat structure in reading order

**Structure**:
```json
[
  {
    "type": "text",
    "text": "Introduction",
    "text_level": 1,
    "bbox": [259, 533, 1377, 593],
    "page_idx": 0
  },
  {
    "type": "table",
    "table_body": "<table><tr><td>A</td>...</table>",
    "table_caption": ["Table 1: Results"],
    "table_footnote": ["* p < 0.05"],
    "img_path": "images/3a7f5e2b...jpg",
    "bbox": [260, 650, 1380, 1200],
    "page_idx": 0
  },
  {
    "type": "equation",
    "latex_text": "f(x) = \\int_{0}^{\\infty} e^{-x^2} dx",
    "img_path": "images/8c9d1a4f...jpg",
    "bbox": [496, 800, 1158, 850],
    "page_idx": 0
  }
]
```

**Content Types**:

#### Text Block
```json
{
  "type": "text",
  "text": "Content...",
  "text_level": 1,  // 1=h1, 2=h2, 3=h3, null=paragraph
  "bbox": [x0, y0, x1, y1],
  "page_idx": 0
}
```

#### Table Block
```json
{
  "type": "table",
  "table_body": "<table>...</table>",  // HTML table
  "table_caption": ["Table 1: Title"],
  "table_footnote": ["* Note"],
  "img_path": "images/hash.jpg",
  "bbox": [x0, y0, x1, y1],
  "page_idx": 0
}
```

#### Equation Block
```json
{
  "type": "equation",
  "latex_text": "E = mc^2",
  "img_path": "images/hash.jpg",
  "bbox": [x0, y0, x1, y1],
  "page_idx": 0
}
```

#### Image Block
```json
{
  "type": "image",
  "img_caption": ["Figure 1: Diagram"],
  "img_footnote": ["Source: ..."],
  "img_path": "images/hash.jpg",
  "bbox": [x0, y0, x1, y1],
  "page_idx": 0
}
```

#### Code Block
```json
{
  "type": "code",
  "code_text": "def example():\\n    pass",
  "code_language": "python",
  "code_caption": ["Listing 1"],
  "sub_type": "algorithm",  // or "code"
  "img_path": "images/hash.jpg",
  "bbox": [x0, y0, x1, y1],
  "page_idx": 0
}
```

#### List Block
```json
{
  "type": "list",
  "list_items": [
    "First item",
    "Second item"
  ],
  "sub_type": "bullet",  // or "number"
  "bbox": [x0, y0, x1, y1],
  "page_idx": 0
}
```

**Use Cases**:
- Content extraction for ML/AI
- RAG (Retrieval-Augmented Generation) ingestion
- Search indexing
- Simpler parsing than middle.json
- Sequential content processing

**Coordinate System**: Normalized [0, 1000] for compatibility

**Control with**: `dump_content_list=True` (default)

**Example Usage**:
```python
import json

result = pipeline.process("document.pdf", "output/")
content_list = result["content_list"]

# Extract all formulas
formulas = [
    block["latex_text"]
    for block in content_list
    if block.get("type") == "equation"
]

# Extract all tables
tables = [
    block["table_body"]
    for block in content_list
    if block.get("type") == "table"
]

# Extract headings
headings = [
    (block["text_level"], block["text"])
    for block in content_list
    if block.get("type") == "text" and block.get("text_level")
]
```

### Images Directory

**Path**: `{output_dir}/images/`

**Purpose**: Extracted visual elements

**Contents**:
- Tables (rendered as images)
- Formulas (rendered as images)
- Figures and diagrams
- Charts and plots

**Naming**: SHA256 hash of content + extension
- Example: `3a7f5e2b8c9d1a4f6e7d2b5c8a9f1e4d.jpg`
- Ensures uniqueness and deduplication

**Formats**: JPG, PNG

**Referenced by**: All JSON outputs via `img_path` field

**Use Cases**:
- Displaying visual elements
- Training computer vision models
- Document archiving
- Visual verification

**Example**:
```python
content_list = result["content_list"]

# Find all table images
table_images = [
    block["img_path"]
    for block in content_list
    if block.get("type") == "table" and "img_path" in block
]

print(f"Table images: {table_images}")
# Output: ['images/3a7f5e2b...jpg', 'images/8c9d1a4f...jpg']
```

## Controlling Output

Use Settings to control which files are generated:

```python
from ocrrouter import Settings

settings = Settings(
    backend="deepseek",
    openai_api_key="key",

    # Control output files
    dump_md=True,            # Generate markdown ✓
    dump_middle_json=True,   # Generate middle.json ✓
    dump_model_output=True,  # Generate model.json ✓
    dump_content_list=True,  # Generate content_list.json ✓
    dump_orig_pdf=False,     # Don't copy original PDF ✗
    draw_layout_bbox=True,   # Generate layout.pdf ✓
)
```

### Minimal Output (for storage optimization)

```python
settings = Settings(
    dump_md=True,            # Only markdown
    dump_content_list=True,  # And content list
    dump_middle_json=False,  # Skip
    dump_model_output=False, # Skip
    draw_layout_bbox=False,  # Skip
)
```

### Full Output (for debugging/analysis)

```python
settings = Settings(
    dump_md=True,
    dump_middle_json=True,
    dump_model_output=True,
    dump_content_list=True,
    dump_orig_pdf=True,      # Include original
    draw_layout_bbox=True,
)
```

## Coordinate Systems

OCRRouter uses different coordinate systems in different files:

### Model Output (`_model.json`)

- **Format**: `[x0, y0, x1, y1]` (top-left, bottom-right)
- **Range**: Normalized [0, 1]
- **Origin**: Top-left of page (0, 0)
- **Example**: `[0.157, 0.228, 0.833, 0.253]`

**Convert to pixels**:
```python
width, height = 1654, 2339  # Page dimensions

bbox_normalized = [0.157, 0.228, 0.833, 0.253]
bbox_pixels = [
    bbox_normalized[0] * width,   # x0
    bbox_normalized[1] * height,  # y0
    bbox_normalized[2] * width,   # x1
    bbox_normalized[3] * height   # y1
]
# Result: [259.678, 533.292, 1378.782, 592.167]
```

### Middle JSON (`_middle.json`)

- **Format**: `[x0, y0, x1, y1]`
- **Range**: Absolute pixels
- **Origin**: Top-left of page (0, 0)
- **Example**: `[259, 533, 1377, 593]`

### Content List (`_content_list.json`)

- **Format**: `[x0, y0, x1, y1]`
- **Range**: Normalized [0, 1000]
- **Origin**: Top-left of page (0, 0)
- **Example**: `[157, 228, 833, 253]`

**Why [0, 1000]?**: Compatibility with some document processing standards while maintaining precision.

## Use Cases by File Type

### For Human Readers
- **Use**: `{name}.md`
- **Why**: Clean, readable markdown with proper formatting

### For Quality Verification
- **Use**: `{name}_layout.pdf`
- **Why**: Visual verification of layout detection accuracy

### For ML/AI Pipelines
- **Use**: `{name}_content_list.json`
- **Why**: Simplified structure, easy to parse, flat list

### For Custom Processing
- **Use**: `{name}_middle.json` or `{name}_model.json`
- **Why**: Complete structural data with all metadata

### For Search/Indexing
- **Use**: `{name}.md` or `{name}_content_list.json`
- **Why**: Flat structure with text content

### For Training Data
- **Use**: `{name}_model.json` + `images/`
- **Why**: Original model predictions + extracted visuals

### For Document Archiving
- **Use**: All files with `dump_orig_pdf=True`
- **Why**: Complete record including original
